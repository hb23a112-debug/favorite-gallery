# Favorite Gallery

ComfyUIのサイドバーに「お気に入り管理」タブを追加するカスタムノードです。
生成した画像・動画・音声を日付ごとに見返し、お気に入り・タグ・メモを付けられます。

【スクリーンショットをここに貼る】

## 作った理由

ComfyUIの出力は日付ごとのフォルダに散らばり、似た画像が大量にたまるため、あとから良い候補を探すのに時間がかかっていました。
そこで、元のファイルには触れずに「選んで、印を付けて、見返す」ことだけを担うツールを作りました。

## 機能

- ★でお気に入りの切り替え（元ファイルは移動・変更しない）
- タグ（カンマ区切り）とメモの編集
- 「お気に入りのみ」の絞り込み
- 種類（拡張子）での絞り込み
- 日付範囲での絞り込み
- 作成日ごとのグループ表示（件数つき）
- お気に入りを `output/_favorites/` にまとめてコピー
- 画像・動画・音声に対応
  - 画像：png, jpg, jpeg, webp, gif, bmp
  - 動画：mp4, webm, mov, m4v
  - 音声：mp3, wav, flac, m4a, ogg

## インストール

1. このフォルダを `ComfyUI/custom_nodes/favorite_gallery` として配置する
2. ComfyUIを再起動する
3. 左サイドバーの★アイコンから開く

動作確認環境：【OS / Python / ComfyUIのバージョン】

## 仕組み

- Python（aiohttp）で、ComfyUIのサーバーにAPIを追加しています（`__init__.py`）。
  - `GET /favorite_gallery/files`：outputフォルダ内のメディア一覧を返す
  - `POST /favorite_gallery/toggle`：お気に入りの切り替え
  - `POST /favorite_gallery/meta`：タグとメモの更新
  - `POST /favorite_gallery/export`：お気に入りをコピー
- 画面はJavaScriptで、サイドバータブとして実装しています（`web/favorite_gallery.js`）。
- お気に入り・タグ・メモは `output/favorites.json` に保存します。生成ファイルは一切変更しません。

### 工夫した点

- **作成日時の判定**：`st_birthtime` があればそれを使い、なければ `min(ctime, mtime)` を使います。ファイルをコピーすると更新日時だけが新しくなり、日付の並びが崩れるためです。
- **旧形式データの移行**：以前の保存形式（`{"favorites": [...]}`）を、新形式に自動で読み替えます。
- **コピー時の名前衝突の回避**：`2025-01-01/a.png` のようなパスを `2025-01-01__a.png` に変えて、別フォルダの同名ファイルが上書きされないようにしています。

## 制約と今後

- お気に入りは相対パスをキーにしているため、ファイルを移動・改名すると紐付きが切れます（ファイルのハッシュで紐付ける案を検討中）。
- 保存は直接の上書きです（一時ファイル経由の保存に変更予定）。
- クライアントから受け取ったパスの検証は未実装です（outputフォルダ配下かどうかの確認を追加予定）。
- サムネイルは元の解像度で読み込むため、枚数が多いと重くなります（縮小表示とページ分割を検討中）。
